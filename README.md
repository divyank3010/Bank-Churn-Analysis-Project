# Bank-Churn-Analysis-Project
# Bank Customer Churn Prediction: A Comparative Machine Learning Approach

## 📌 Project Overview
This project investigates customer churn within the banking sector using data analytics and machine learning. The goal is to identify high-risk customers and understand the key drivers behind customer attrition to support better retention strategies.

This project was developed as part of the **Business Data Analytics** module (2026).

## 📊 Analytical Approach
The project follows a standard data science pipeline:
1. **Data Preprocessing:** Cleaning, handling categorical encoding (One-Hot Encoding), and feature scaling.
2. **Exploratory Data Analysis (EDA):** Visualizing churn patterns based on geography, age, and balance.
3. **Modeling:** Implementing and comparing three distinct algorithms:
   - **Logistic Regression** (Baseline model)
   - **Random Forest** (Ensemble method)
   - **Gradient Boosting** (High-performance boosting)
4. **Evaluation:** Assessing performance using Accuracy, Precision, Recall, F1-Score, and ROC-AUC.

## 🚀 Key Results
- **Best Performing Model:** Gradient Boosting.
- **Top Churn Drivers:** Age, Geography (specifically customers in Germany), and Inactive Member status.
